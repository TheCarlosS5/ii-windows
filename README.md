# ii-windows

Port de la interfaz de **Illogical Impulse** ([end-4/dots-hyprland](https://github.com/end-4/dots-hyprland)) a Windows 11, sobre un fork de [Quickshell](https://quickshell.org) que compila y corre en Windows.

Estado: en desarrollo. Ver [PROGRESS.md](PROGRESS.md) y [docs/FEASIBILITY.md](docs/FEASIBILITY.md).

Solo se porta la interfaz: Windows sigue gestionando las ventanas (sin tiling ni reglas).
